# Eventify – Event Registration System

A simple front-end event registration website. Browse events, search and filter by category, register with your details, and cancel registrations. Data is saved in the browser using `localStorage` (demo project, no backend).

## Features

- Event cards with date, time, location and price
- Search and category filter
- Registration form with validation
- My registrations list with total cost and cancel option
- Responsive layout

## Tech stack

HTML, CSS, JavaScript (vanilla)

## Project structure

```
eventify/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

Open `index.html` in any browser. No installation needed.
